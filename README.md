# Not Ur Fan

Lists what Instagram accounts you follow that do not follow you back.

## Requirements

- Python 3
- The Python package listed in [`requirements.txt`](requirements.txt)

## Setup

From the project directory, create and activate a virtual environment, then
install the dependencies:

```zsh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

If you already have a virtual environment for this project, activate that
environment instead of creating another one.

## Run

With the virtual environment active, run:

```zsh
python main.py
```

The program prompts for your Instagram username and password. The password is
entered without being displayed in the terminal.
